# Copier-Template (Phase 6)

Hier entsteht das Projektgerüst, aus dem neue Tools generiert werden:
`copier.yml` (Fragen: Projektname, LTI ja/nein, Ports, Sprachen), Backend-
`config/` samt Settings-Gerüst und konkretem `accounts.User` (ADR-0003),
Vite-Shell, docker-compose, Caddyfile, Keycloak-Setup, CI.

Es wird aus dem konsolidierten Stand von ausleihbar/abstimmbar destilliert und
mit der Generierung von **erkennbar** validiert — siehe
[EXTRAKTIONSPLAN.md](../docs/EXTRAKTIONSPLAN.md), Phase 6.
